# Uplift Hackathon Tournament — GitHub Pages

This is a single-page, responsive static website for a fictional/creative Uplift Hackathon Tournament 2026 concept.

## Deploy on GitHub Pages

1. Create a new GitHub repository, for example `uplift-hackathon`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the Pages URL.

## Images

Each "ADD IMAGE" area is a browser-only preview field. It does not permanently upload images to GitHub. To make images permanent, add image files to the repository and change the relevant `<img src="...">` elements in `index.html`.
